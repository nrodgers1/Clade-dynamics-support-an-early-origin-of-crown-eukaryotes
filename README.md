# Clade dynamics support an early origin of crown eukaryotes


This repository stores the code associated with the paper "Clade dynamics support an early origin of crown eukaryotes" 2026 written by Corentin Loron and Niall Rodgers.

This script is a simple jupyter notebook which plots the equations detailed in the paper, using the simple analytical approximation proposed. All results can be directly reproduced from these equations.
