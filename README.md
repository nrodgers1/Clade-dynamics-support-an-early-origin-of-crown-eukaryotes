# Reconciling the tempo and timing of eukaryote emergence with clade dynamics and the fossil record 


This repository stores the code associated with the paper "Reconciling the tempo and timing of eukaryote emergence with clade dynamics and the fossil record" 2026 written by Corentin Loron and Niall Rodgers.

This script is a simple jupyter notebook which plots the equations detailed in the paper, with a small amount of numerical solving when required. All results can be directly reproduced from these equations. 

For questions about the code please email: Niall.Rodgers at ed.ac.uk 

The naming convention of the repository comes from when the work began but the conclusions should reflect the updated title and conclusions reflected in the paper "Reconciling the tempo and timing of eukaryote emergence with clade dynamics and the fossil record".
